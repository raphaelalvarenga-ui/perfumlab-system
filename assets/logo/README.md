# Logo del negocio

Guarda aqui el logo oficial del negocio.

Nombre del archivo del logo:

```text
logoperfumlab.png
```

Cuando el logo este listo, se puede convertir a:

```text
logoperfumlab.ico
```

`logoperfumlab.ico` sera el archivo ideal para cambiar el icono de la ventana de Tkinter y del ejecutable de Windows.
